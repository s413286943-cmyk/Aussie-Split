# 澳新 2027 每日主题图 prompt

风格和 2026 澳洲行程的配图一致：写实、电影感的风景照，横版 16:9，没有人物特写、没有文字和 logo。

## 怎么用

1. 每条 prompt 末尾都已经带上统一风格句，直接整段复制到 gpt-image-2.5。
2. 尺寸选横版 16:9（例如 1536×864 或 1920×1080）。
3. 存成下面写好的文件名，放进仓库的 `public/nz2027/`，格式 jpg / png / webp 都可以，单张最好压到 1 MB 以内。
4. 运行 `npm run nz2027:import`（或者把图片发给我）。导入会按文件名自动配到对应的那一天；没放图的日子继续显示纯色封面。

统一风格句（已包含在每条里）：

> Photorealistic cinematic travel photograph, 16:9 landscape, natural golden-hour light, rich but true-to-life colours, shallow atmospheric haze, wide-angle composition with clear foreground, middle ground and background, no people in focus, no text, no logos, no watermarks.
